## The short version

A market storefront theme is a **presentation of the Harvest market contract**. It owns five things: a header, a footer, a homepage hero, a homepage layout and a stylesheet. Every other page is shared Astro markup that the theme styles through its own site class. The backend stores and validates the same content shape for every market-only theme, so a new theme needs no data migration.

A website's theme is fixed when the website is created: saving a draft with a different theme is rejected (`WEBSITE_TEMPLATE_IMMUTABLE`). To change theme, a manager creates a new website in the Website Library and publishes it when ready.

## How a request becomes a themed page

1. **Host resolution.** `apps/storefront/src/middleware.ts` resolves the request's host to a storefront through the backend registry and puts the result in `Astro.locals.storefront` (a `StorefrontContext`). Its `appearance` is the published website (or, inside the editor preview, the authorized draft).
2. **Route.** Astro runs the page under `apps/storefront/src/pages/`. Each page reads its data (market dates, catalog, vendors, cart) on the server and renders inside `SiteLayout`.
3. **Layout and theme detection.** `apps/storefront/src/layouts/SiteLayout.astro` reads `appearance.theme`. For a market, `marketOnlyTheme(appearance)` returns `'meadow'`, `'hearth'`, `'pasture'` or `undefined`. The layout then:
   - links the theme's stylesheet (`pasture.css` through a `?url` import), and only that theme's;
   - writes `data-storefront-theme="pasture"` and `data-theme-palette="<palette>"` on `<html>`, plus `data-storefront-hover` and the theme CSS variables from `storefrontThemeStyle`;
   - wraps the page in `<div class="pasture-site market-text-links">`;
   - renders the theme's `Header` above `<main id="main">` and its `Footer` below.
4. **Homepage choice.** `apps/storefront/src/pages/index.astro` picks the homepage component. While a market is open it renders the shared `MarketDayHome` (see [Market Day](08_MARKET_DAY.md)). Otherwise, for a backend market on Pasture, it renders `components/pasture/MarketHome.astro`.
5. **Other pages.** Shop, product, cart, checkout, market dates, vendors, applications, about, contact, FAQ, policies and terms render shared components. The theme changes how they look, not what they contain.

## What the theme owns and what it shares

| Area                                                 | Owner                                                                                              |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Header, footer, homepage hero, homepage layout, art  | Theme folder, for example `apps/storefront/src/components/pasture/`                                |
| Stylesheet                                           | Theme file, for example `apps/storefront/src/styles/pasture.css`, linked only for that theme       |
| Page structure switches                              | One entry in `themePageStructures` (`packages/theme/src/theme-page-structure.ts`)                  |
| Saved content (homepage order, copy, page sections)  | Shared Harvest contract in `packages/theme/src/storefront.ts` and `website-section-contract.ts`    |
| Add Section library                                  | Shared Harvest renderers in `apps/storefront/src/components/home/`, registered per theme           |
| Shop, product, cart, checkout, confirmation          | Shared routes and React islands                                                                    |
| Market dates, vendors, applications pages            | Shared routes with `MarketDateList`, `MarketVendorCards`, `ShopMarketSelection`                    |
| About, contact, FAQ, policies, terms                 | Shared routes with `WebsitePageRegion`, `ContactForm`, `PolicyListPage` and the closing invitation |
| Market Day homepage                                  | Shared `MarketDayHome`, which borrows the theme's hero                                             |
| Header behaviour (mobile menu, scrolled state, cart) | Shared `lib/market-theme-header.ts`                                                                |
| Navigation list                                      | Shared `marketSiteNavigation` and `marketNavigation` in `lib/market-website.ts`                    |
| Customer account area                                | Shared dashboard shell. Never themed.                                                              |
| Prices, stock, eligibility, payment, sign-in         | Backend. Never touched by a theme.                                                                 |

## The content model a theme reads

A market website's `appearance` (validated by `storefrontAppearanceSchema`) holds, among other things:

| Field                  | Holds                                                                                                                                                                                                                         |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme`                | The theme ID, for example `'pasture'`.                                                                                                                                                                                        |
| `palette`              | One of `sage`, `terracotta`, `blue`, `charcoal`. Each theme maps these to its own colors.                                                                                                                                     |
| `buttonShape`          | `square`, `soft` or `pill`.                                                                                                                                                                                                   |
| `buttonHover`          | `lift`, `darken` or `outline`.                                                                                                                                                                                                |
| `homepage`             | Hero `title`, `introduction` and `image`.                                                                                                                                                                                     |
| `harvestComposition`   | Homepage order: the five native sections `hero`, `markets`, `vendors`, `categories`, `closing` plus library sections.                                                                                                         |
| `market`               | Market copy (`text`), hero button destinations, hero image asset, card color themes, `heroShape`, `typography` and the three market pages (`market-dates`, `vendors`, `applications`) with `enabled`, `title`, `description`. |
| `pageSections`         | Library sections in each page's `before` and `after` region, plus `closingPosition`.                                                                                                                                          |
| `about`                | About page switch, title and story sections.                                                                                                                                                                                  |
| `contact`              | Contact page switch, copy, public contact details and `form.fields`.                                                                                                                                                          |
| `faq`                  | FAQ page switch, copy and questions.                                                                                                                                                                                          |
| `policies`             | Policies page switch, heading, introduction and policies.                                                                                                                                                                     |
| `marketTerms`          | Market Terms & Conditions, shaped like `policies`.                                                                                                                                                                            |
| `textSizes`            | Per-section heading and paragraph scale percentages.                                                                                                                                                                          |
| `categoryPresentation` | Category visibility, order and images.                                                                                                                                                                                        |

A theme reads these through helpers, never by guessing defaults:

- `marketText(appearance, key)` returns market copy or its fallback from `marketTextFields`.
- `marketPage(appearance, id)` and `marketPageAvailable(appearance, id, preview)` return a market page and whether it is reachable. A disabled page is still reachable inside the editor preview.
- `storefrontText(appearance, key)` returns shared labels such as `headerAboutLabel` and `footerAboutLabel`. It reads vendor text, which market websites cannot store, so on a market it always returns the fallback ("About", "Our story").
- `headingOnlyMarketText(theme)` lists market copy the theme does not show.
- `themePageStructure(theme)` returns the theme's page structure rules.

## Boundaries a theme must not cross

- **No admin code in customer pages.** Storefront pages never import from `apps/admin` or admin services.
- **No new hydration to share styles.** Astro renders on the server. Use React islands only where the page already has one (cart button, checkout, contact form, Market Day live state).
- **No client islands importing the `@market/storefront-core` root.** It re-exports server-only request code. Islands import client-safe subpaths such as `@market/storefront-core/stock`.
- **No commerce in the editor preview.** Cart, checkout and confirmation render a "not available in the visual editor" message in the preview. Forms and buttons are blocked by the preview bridge.
- **No vendor content on a market theme.** The schema rejects `vendor` settings on a market-only theme, and market-only themes are never offered to vendors.
