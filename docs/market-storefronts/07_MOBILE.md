# 7. Mobile

> **READ-ONLY REFERENCE.** Do not edit this file during feature work. If the code disagrees with it, stop and ask the developer. Change it only when the developer explicitly asks. Verified against `farmers-market-platform-web` (working tree based on `fb09982`) and `farmers-market-platform` (working tree based on `ea2c77a`), November 27, 2026.

**Layer: Structure, then Styling, in separate parts.** Part A is what the markup and behaviour provide on small screens, for every theme. Part B is the breakpoints and what changes at each, with Pasture's values.

## Part A: Structure on small screens (every theme)

- **One markup for every width.** There is no separate mobile page or component. The header always contains both the inline navigation and the mobile menu. CSS decides which one shows.
- **Mobile menu.** The header's `<details data-theme-menu>` holds a `<summary aria-label="Open navigation menu">` and a `<nav aria-label="Mobile navigation">` with Home and the header links. `mountMarketThemeHeader` keeps `aria-expanded` and the summary label in step and closes the menu on Escape (focus returns to the button), on a link click and on a click outside it.
- **Sticky header with a scrolled state.** `data-scrolled` is set once the page scrolls past 8px, at every width.
- **Viewport.** `SiteLayout` sets `<meta name="viewport" content="width=device-width, initial-scale=1">`. The theme wrapper clips sideways overflow, so wide art never makes the page scroll sideways.
- **Hover is an extra, never a requirement.** Nothing is only reachable on hover.
- **Reduced motion** applies at every width.
- **Checkout order on phones.** On narrow screens the shared checkout puts the order summary (or the review summary) above the form. The width is in the shared breakpoints in Part B.
- **The editor previews three widths.** Desktop (full), Tablet (768px) and Mobile (390px) size the preview iframe. They do not emulate touch, so also check a real narrow browser window.

## Part B: Styling breakpoints

### Pasture's breakpoints

| Query               | Where in `pasture.css` | What changes                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `max-width: 1100px` | Header                 | `--pw-header-height` drops from 82px to 72px. The inline navigation hides and the menu button shows. The header becomes brand plus actions.                                                                                                                                                                                                                                           |
| `min-width: 861px`  | Hero                   | The hero copy uses a wider container than the page so it sits further left beside the photo.                                                                                                                                                                                                                                                                                          |
| `max-width: 860px`  | Responsive             | The hero photo moves below the copy, still meeting the right edge, with the fields running across its foot. The hero loses its minimum height. The top leaf and one cloud hide, and the sprig moves. The closing banner and the footer become one column.                                                                                                                             |
| `max-width: 760px`  | Small screens, 2       | The shop becomes one column. The category list stops being sticky, its heading is kept for screen readers only, and the category pills become one swipeable row with no hover lift. The date banner stacks and its picker button goes full width. Product cards go two across with tighter padding and smaller type. The cart summary stops being sticky. Vendor cards go one across. |
| `min-width: 761px`  | Contact form           | The market contact form runs in two columns. The message and any long-answer field (`[data-wide]`) span both. Below 761px it is one column.                                                                                                                                                                                                                                           |
| `max-width: 700px`  | Responsive             | Hero buttons go full width. The next-date tag fills the row. Section heading rules hide. Homepage category tiles become a swipeable row with scroll snapping.                                                                                                                                                                                                                         |
| `max-width: 420px`  | Header                 | The brand mark shrinks to 36px and the brand name and action gaps tighten.                                                                                                                                                                                                                                                                                                            |

Menu styling at 1100px and below: the menu opens as a cream panel under the header between the gutters, with full-width rows, a hover indent and the current page filled with the leading color.

Touch targets (rule): icon controls (cart, account, menu, remove) are at least 44 by 44px at every width, and shared buttons keep their minimum heights. Shared hover lifts on cards only apply under `@media (hover: hover)`, so touch screens never get a stuck lift.

### Rules for a new theme's responsive styles

1. **Put responsive rules in one or two clearly marked blocks** near the end of the theme file, after the rules they change, so they win by order.
2. **Reuse the shared widths where you can** (760px for shop, cart and checkout; 700px for homepage sections) so the theme and the shared layout change at the same point.
3. **Pick the header breakpoint from the links.** Switch to the menu before the full header link list wraps. With About, Contact and all three market pages on, Pasture's header needs about 1100px.
4. **Stack the hero before the copy and the image fight for width.** Keep the hero image visible on phones.
5. **Prefer swipeable rows to long stacks** for chips and small tiles (filters, categories), with the scrollbar hidden and the row bleeding to the gutters.
6. **Do not shrink text below readable sizes** to fit. Wrap or stack instead.
7. **Check at 1280, 1100, 860, 768, 390 and 360px**, with the longest market name and title you can expect, an empty hero image and a cart with two vendors.
