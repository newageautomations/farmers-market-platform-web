## Screens and authoritative rereads

Products now lists/searches/pages only owned catalog rows, loads owned detail and rereads metadata, Variant metadata and exact integer-minor-unit price changes. Create returns the backend Product ID and loads that Product. Variant creation obtains canonical currency from the owning Vendor Channel projection and selects only compatible options attached to the Product. It has no USD fallback or arbitrary option-ID entry.

Inventory displays current backend Product/Variant names and SKU alongside integer on-hand, allocated and physical-free values, count, asOf and cursor pagination. Restock and signed adjustments retain confirmations/idempotency and reread current stock. It calls no analytics inventory root. Only existing canonical physical inventory records appear; newly created but unprovisioned Variants are not assigned guessed zero stock. Source provisioning remains the existing backend responsibility.

Orders now lists placed owned operational portions, with Direct/Market filters, pagination, actual domain Market name, occurrence/time, placed date, pickup state and exact quantities. Detail uses the same authoritative projection and existing movement-derived remaining quantities. Customer Aggregate and other Vendors' Seller portions cannot become Vendor operational rows. Production operational views do not fabricate purchase money. Cancellation remains separate from refund settlement.

Markets shows the current domain name within an authorized business relationship, supports the paged/searchable owned Variant selector and reads actual current publication per listing. Publish/unpublish completion triggers authoritative rereads. The current state is PUBLISHED, UNPUBLISHED or RECONCILIATION_REQUIRED, never a remembered command receipt. Unpublish remains available for an existing relationship even when publication eligibility has changed.

Overview now uses bounded catalog/order total reads. Analytics uses exact ALLOWED/DENIED/UNKNOWN/UNCONFIGURED presentation and retains separate currencies, UTC ranges, generation cursors and source metadata. CRM keeps its existing owned API and purchase-history semantics. The real suite exercises summary, trend, Product, Market and Occurrence analytics views.

Two defects found by real integration are fixed: anonymous native `me` rejection now leads to sign-in; a denied foreign resource triggers a fresh bootstrap at the safe Vendor route instead of repeatedly reloading the denied detail. Same-generation authority loss clears prior tenant content; stale-generation failures cannot clear a newly selected tenant. Role and human-membership revocation are both proved in the same cookie session for Vendor and Market.
