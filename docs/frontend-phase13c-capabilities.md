# Phase 13C Market capability characterization

Inspected current source on October 5, 2026 before broad implementation. The backend is strictly read only. All paths below are relative to `E:\coding\farmers-market-platform`. Phase 13B.5 real integration evidence characterizes the permanent contracts; new tests use frontend fixtures and HTTP mocks only.

Every Market workflow requires native `me`, the exact selected Channel, `ownMarketIdentity`, active current principal `marketAdmin` membership and the intersection of fresh identity grants with selected native grants. Suspended Markets remain manageable under `TenantAccessPolicy.requireMarket`; generation and enabled offerings require active status, and analytics separately requires active status. No URL, first membership, Seller or stored ID determines Market identity.

Source prefix for abbreviated `services/` paths is `src/plugins/farmers-market/`; other plugin paths start at `src/plugins/`. Current schema is regenerated by the frontend's read-only AST extraction. Plugin composition was inspected for PlatformIdentityPlugin, FarmersMarketPlugin, MarketplaceCommercePlugin, AnalyticsPlugin and BillingEntitlementsPlugin. `ownOccurrenceOperations` is an older capped compatibility projection; the new paged root is used exclusively. `marketOfferingDomainTimeEligible` is optional domain/time information and is not needed or computed by this UI.

Market operations select only operational references, Vendor reference, native/pickup/fulfillment state, safe Variant line labels/quantities and pickup promise. No customer identity/contact/address, finance, payment/provider data, fulfillment commands, cancellation of Vendor orders or refunds. Analytics selects 13 operational counters only, never money or customer profiles. Communication analytics roots are not consumed.
