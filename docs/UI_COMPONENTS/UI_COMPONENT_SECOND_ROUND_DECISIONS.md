## Interpretation boundaries

DDN is a disclosure choice, not approval to replace native selects, searchable comboboxes or feature state. Each nested disclosure remains independent. First-round CRD-04 is a retained specialist, so the ordinary DDN-03 selection does not erase it.

BDG-02 approves appearance, not a universal status enum/health map. Preserve exact domain meaning and accessible text with color. BDG-03 booth state mapping and map functionality remain; BDG-04 readiness/capability calculations and information stay unchanged. KPI high/low values are not inherently good/bad; examples such as 24 total, 20 assigned and 4 unassigned are illustrative, not new calculations or hardcoded data.

ALT severity cannot invent outcomes or hide partial/uncertain failures. Preserve safe errors, urgent/polite announcements, request state and retry flows. EMP means genuinely empty, distinct from loading, API errors and unavailable data. LOD consolidation changes spinner presentation only; no new fetching, guards, caches, retries or skeleton replacement is authorized. The current gallery spinner is a static ring, not proof of an animation contract.

TBL mobile improvement must retain all important information, headers/captions and semantic associations. Do not truncate, hide, semantically reorder or omit data to avoid horizontal scrolling; document exceptionally wide-data limitations rather than create unreadable columns. TBL-03 remains distinct. Its description allocation target is about 0.8 times its measured current width, not a 20 percentage-point decrease of table width. Current source has no explicit description-width rule, so baseline measurement is future browser work; preserve description text, calculations, formatting, print and responsiveness.

TAB-03 remains real route anchors/links with hrefs, deep links, history and modifier clicks; TAB-01 styling does not replace it with client-only tab state. TAB-02 retains editor tools/panels. PAG counts/ranges come from actual backend/current page data, including empty/final pages; cursor/offset/query/independent regions remain feature-owned.

MOB source inspection found AdminApp's Refresh workspace, AccountModes Your account/Account mode/conditional Business, AdminShell callback Sign out, and CustomerLayout's Visit storefront or Explore markets plus POST `/api/account` logout with hidden `action=logout`. Preserve applicable real actions/conditional availability in menu content, authorization, active route and workspace context. Do not infer actions from synthetic gallery controls, expose admin/vendor/market links to customers, rewrite logout or harmonize breakpoints without a separate decision. Customer native links/disclosure/logout form retain no-JS behavior where feasible; the React admin architecture remains separate.

SCH dashboard and consumer choices are approved variants, not undocumented competitors. Customer-facing sections follow SCH-01; public sections do not all acquire dashboard-card structure. PGH remains unchanged regardless of shell, section or mobile decisions.
