## Required backend contracts

| Blocker   | Minimum safe addition                                                                                                                      | Safe current behavior                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| VENDOR-B1 | Owned bounded catalog list/detail, canonical Vendor currency and compatible variant options with ownership checked before filtering/paging | No native broad read or Shop workaround. Create product command available; catalog edit/variant selection unavailable live                 |
| VENDOR-B2 | Independent core physical inventory read for own operational grants, named variant/SKU projection and current asOf                         | Existing analytics inventory read is optional. Operational commands are never gated by optional billing; selection needs a safe owned read |
| VENDOR-B3 | Owned operational order list plus direct/Market kind and pickup occurrence enrichment                                                      | Owned detail lookup works; list and missing kind are explicitly unavailable                                                                |
| VENDOR-B4 | Safe Market display name within owned relationship projection                                                                              | Neutral relationship title; no inferred branding/name                                                                                      |
| VENDOR-B5 | Authoritative per-listing publication-state read                                                                                           | Latest command receipt displayed only as a receipt, not current publication truth                                                          |
| VENDOR-B6 | Own capability/boundary availability projection distinguishing allowed, denied, unknown and unconfigured                                   | Unknown does not silently become allowed; core operational UI continues independently                                                      |

Fresh membership `staff` can read its owned projections with grants but cannot execute owner-only commands. Development permission presets label native permission combinations; they do not define new backend roles. Production never imports fixture business data or falls back to fixtures on errors.

## Phase 13B.5 addendum

The preceding content records the historical phase and remains historical evidence. Phase 13B.5 adds later backend and real integration proof in [the new implementation report](frontend-phase13b5-integration-implementation.md). VENDOR-B1 through VENDOR-B6 and Phase13A-B2 are CLOSED: owned catalog list/detail/canonical currency/options, independent operational inventory, owned operational orders, current Market display names, native publication state, exact optional boundary availability and current own Market identity. Phase13A-B1 public hostname/discovery, B3 production many-domain cookie/CORS/CSRF and B4 Market communications remain OPEN.

The production adapters use named generated contracts. Inventory requires ManageOwnInventory under the existing owner policy and remains usable when analytics is denied or unconfigured. Market uses ownMarketIdentity for shared bootstrap only. Publication state is reread from actual native/domain facts. ownEntitlements stays separate from ownFeatureAvailability. Eight bound and one unbound real browser tests, ten backend contract groups per profile, full recursive Phase1-11 plus Phase12 backend regressions, eighty frontend unit tests, twenty-one frontend browser regressions and both builds pass. The protected vendure DB was untouched; no real provider, remote Git or deployment operation occurred. [Evidence](evidence/phase13b5/acceptance.json) contains the full A through DC list.
