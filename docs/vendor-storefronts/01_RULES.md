**Layer: Structure.** How page rules are chosen for a vendor website, and the rule values that differ from the market standard.

## How a rule set is chosen

`themePageStructure(theme, kind)` in `packages/theme/src/theme-page-structure.ts`:

| Kind        | Theme                                                                              | Rule set                                        |
| ----------- | ---------------------------------------------------------------------------------- | ----------------------------------------------- |
| `'VENDOR'`  | Any of `vendorStandardThemes` (Harvest, Editorial Market, Modern Farmhouse, Bloom) | `vendorStandard`                                |
| `'VENDOR'`  | Anything else                                                                      | Historical (all off)                            |
| `'MARKET'`  | Pasture, Meadow, Hearth                                                            | `marketStandard`                                |
| `'MARKET'`  | Harvest, Editorial Market                                                          | `marketStandard` with `marketDayBoothCards` off |
| `'MARKET'`  | Anything else                                                                      | Historical (all off)                            |
| `undefined` | Read as `'MARKET'`. Use only where the kind is genuinely unknown.                  |                                                 |

A new vendor theme is added to `vendorStandardThemes`. It never gets its own entry unless the developer approves a different value.

## Values

`vendorStandard` starts from `marketStandard` and changes only the rows marked **Differs**.

| Rule                   | Vendor value                               | Market value              |             | Why                                                                                                                                   |
| ---------------------- | ------------------------------------------ | ------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `headingOnlyPages`     | `policies`, `terms-and-conditions`         | Same                      |             |                                                                                                                                       |
| `noClosingPages`       | `policies`, `terms-and-conditions`         | Same                      |             |                                                                                                                                       |
| `footerOnlyPages`      | `faq`, `policies`, `terms-and-conditions`  | Same                      |             |                                                                                                                                       |
| `shortHeroPages`       | `contact`, `faq` at `shortHeroHeight: 220` | Same                      |             |                                                                                                                                       |
| `shopPagination`       | `'numbered'`                               | Same                      |             | Applies to `/products`.                                                                                                               |
| `sectionImageShape`    | `true`                                     | Same                      |             |                                                                                                                                       |
| `ctaButtonStyle`       | `true`                                     | Same                      |             |                                                                                                                                       |
| `sectionSpaceDefault`  | `32`                                       | Same                      |             |                                                                                                                                       |
| `shopAvailabilityNote` | `false`                                    | Same                      |             |                                                                                                                                       |
| `lockedTopPages`       | `[]`                                       | `vendors`, `applications` | **Differs** | Those are market pages. A vendor website has none of them.                                                                            |
| `marketTermsPage`      | `false`                                    | `true`                    | **Differs** | Vendor terms stay the plain-text terms with revisions that checkout asks shoppers to accept.                                          |
| `marketContactForm`    | `false`                                    | `true`                    | **Differs** | Vendors keep their existing fixed inquiry form. Manager-added fields are a market feature with backend support for markets only.      |
| `aboutStarter`         | `false`                                    | `true`                    | **Differs** | The starter text talks about a market and links to Market Dates, which a vendor website does not have.                                |
| `marketStarterText`    | `false`                                    | `true`                    | **Differs** | The written example policies and terms speak as a market.                                                                             |
| `marketDayBoothCards`  | `false`                                    | `true`                    | **Differs** | Market Day is a market homepage.                                                                                                      |
| `fixedFindUs`          | `{ initial: 4, more: 8 }`                  | `null`                    | **Differs** | Vendor only. See [Find Us](03_FIND_US.md).                                                                                            |
| `conciseCommerce`      | `false`                                    | `true`                    | **Differs** | Vendor cart and checkout keep their general guidance (for example "Enter your pickup contact. You can purchase without an account."). |

## Where each rule is read

| Rule                                  | Storefront                                                                                                                                                               | Admin editor                                      |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| `footerOnlyPages`                     | `home/HarvestHeader.astro`, `editorial-market/ShopHeader.astro`, `legacy-modern-farmhouse/Header.astro`. Premium Farmhouse's header already leaves FAQ and Policies out. | None                                              |
| `headingOnlyPages`, `shortHeroPages`  | `supportsWebsitePageHero`, `effectiveWebsitePageSections` (`packages/theme/src/website-page-heroes.ts`)                                                                  | Same helpers                                      |
| `noClosingPages`                      | `pages/policies.astro` (Harvest, Bloom), `editorial-market/Content.astro`, `modern-farmhouse/Content.astro`                                                              | `VisualStorefrontEditor` (Policies closing row)   |
| `shopPagination`                      | `home/HarvestShop.astro` (every vendor theme's shop). `editorial-market/Shop.astro` and `modern-farmhouse/Shop.astro` also read it but are no longer routed.             | None                                              |
| `conciseCommerce`                     | `pages/cart.astro`, `pages/checkout/index.astro`, `VendorPreorderBanner.astro`                                                                                           | None                                              |
| `shopAvailabilityNote`                | `ProductCards.astro`. Farmhouse's own cards follow the same rule without reading it.                                                                                     | None                                              |
| `sectionImageShape`, `ctaButtonStyle` | Each theme's Image with Text and Call-to-Action Banner renderer                                                                                                          | `WebsiteTextSectionEditor`, `WebsiteBlockEditor`  |
| `sectionSpaceDefault`                 | `.vendor-site` rule in `styles/website-sections.css`                                                                                                                     | `SectionSpaceField` in `WebsiteEditorContext.tsx` |
| `fixedFindUs`                         | `pages/find-us.astro`, `modern-farmhouse/FindUs.astro`, `MarketSchedule.astro`, the hero helpers                                                                         | `VisualStorefrontEditor`, `FindUsEditor`          |
